# Real-Time Fraud & Anomaly Detection System

A production-ready machine learning system to detect fraudulent credit card transactions in real-time.

## Project Structure
- `data/`: Raw and processed datasets.
- `models/`: Serialized model files (.pkl, .json).
- `src/`: Core logic (training, API, utilities).
- `notebooks/`: Exploratory Data Analysis (EDA) and prototyping.
